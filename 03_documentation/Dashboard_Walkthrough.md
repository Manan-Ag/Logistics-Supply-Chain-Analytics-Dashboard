# Dashboard Walkthrough

## Page 1 — Executive Financial Overview

This dashboard provides leadership visibility into:
- Revenue trends
- Net profitability
- Shipping cost performance
- Regional operational efficiency

Primary KPIs:
- Net Profit
- Net Profit Margin %
- Shipping Cost Trends

---

## Page 2 — Delivery Performance Analytics

This dashboard focuses on operational logistics performance.

Primary metrics include:
- On-Time Delivery %
- Carrier SLA Compliance
- Delay Root Cause Analysis
- Product Damage Rate
- Return Rate %

The dashboard helps identify operational bottlenecks impacting customer fulfillment performance.

---

## Page 3 — Inventory & Warehouse Analytics

This dashboard monitors:
- Warehouse inventory health
- Stockout risk exposure
- Supplier reliability
- Safety stock thresholds

The dashboard supports inventory optimization and operational continuity planning.
